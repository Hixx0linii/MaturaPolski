Jak uruchomić tę stronę w 1 minutę na GitHub Pages (100% za darmo)

Wszystkie pliki HTML są w 100% samowystarczalne (nie wymagają instalacji, serwera ani połączenia z internetem). Możesz je wrzucić na GitHub i mieć stały dostęp ze smartfona, tabletu i laptopa!

1
Stwórz repozytorium
Zaloguj się na github.com, kliknij New repository (np. o nazwie matura-polski) i ustaw jako Public.
2
Wrzuć ten folder
Przeciągnij całą zawartość tego folderu (w tym plik index.html i podkatalog Fiszki/) do repozytorium i kliknij Commit changes.
3
Włącz GitHub Pages
W repozytorium przejdź do: Settings ➔ Pages ➔ Source: Deploy from a branch, wybierz gałąź main oraz folder / (root) i kliknij Save.
4
Gotowe! Masz stronę online
Po ~30 sekundach Twoja strona będzie dostępna pod adresem: https://twój-login.github.io/matura-polski/!
